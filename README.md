# 비디오 컷

라이브 녹화 영상(MP4, H.265/H.264)에서 의미 없는 구간을 자동으로 찾아 확인 후 잘라내는 윈도우 프로그램. 인터넷 없이 동작합니다.

## 자동으로 찾는 구간
- 시작 대기 화면, 렉으로 멈춘 부분(기본 1.5초 이상), 긴 대기 화면
- 흐림·가림 화면(유료회원 대기 등)
- 끝난 뒤 검은 화면

## 사용 순서
1. 영상 열기(또는 창에 끌어다 놓기) → 자동 분석
2. 오른쪽 목록에서 구간을 하나씩 확인 — 미리보기 5장, 구간·경계 재생
   - Space: 자르기/살리기 전환, Del: 구간 지우기, 시작/끝 조정 버튼
3. '확인 완료 — 잘라서 저장'
   - 자동: H.265 원본은 무손실로 빠르게, 그 외는 H.265로 인코딩
   - 무손실은 키프레임 기준으로 잘려 자르는 지점이 조금 앞당겨질 수 있음 → 정확히 자르려면 'H.265 인코딩'

그래픽카드(엔비디아 NVENC / 인텔 / AMD)가 있으면 자동으로 사용하고, 안 되면 CPU로 처리합니다.
설정에서 멈춤·흐림·검은 화면 기준을 바꾸고 '다시 찾기'로 바로 반영할 수 있습니다.

FFmpeg(GPL) 빌드를 함께 배포합니다: https://github.com/BtbN/FFmpeg-Builds
